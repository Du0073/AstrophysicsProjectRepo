PHASE 1

SDSS DR17 SQL & Normalized SQLite

Joins PhotoObj, SpecObj, galSpecExtra, and zooSpec under FlatLambdaCDM(H₀=70, Ωₘ₀=0.3). Computes physical re_kpc from petroR50_r, concentration R90/R50, M_r, colors, and stores all quantities as unitless SQLite REAL.

PHASE 2

Automated RGB & Multi-Band FITS

Resumable multi-threaded 128×128 SDSS RGB cutout acquisition plus calibrated g, r, i FITS showcase processing with WCS Cutout2D, NaN masking, sky subtraction, and Lupton arcsinh stretching.

PHASE 3

Dual-Track ML & Deep Learning

Separate classifier folders: classifiers/astronn_and_astroml/ (Random Forest + astroNN Bayesian MC-Dropout Galaxy10CNN) and classifiers/tensorflow_cnn/ (custom 4-block TensorFlow CNN with 360° augmentation).

PHASE 4

Zero-Backend Interactive Atlas

src/export_dashboard.py exports SQLite v_galaxy_dashboard, predictions, and evaluation metrics to compact JSON/JS consumed directly by this Plotly.js web application with zero backend server required.
